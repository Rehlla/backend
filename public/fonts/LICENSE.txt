WHAT THIS MEANS FOR THIS PROJECT
-------------------------------
This is a LOCAL PROTOTYPE copy. The terms above restrict embedding the font in
shipped software and website content, so before this leaves a local prototype:

  - keep using SF Arabic only for the mock-up of the Rehla prototype, or
  - swap the @font-face in Rehla/index.html to a font you may embed, e.g.
    * Alexandria / IBM Plex Sans Arabic (both on Google Fonts, embeddable) —
      the main web app already uses these, or
    * Geeza Pro / SF Arabic installed on the developer's own Apple device,
      without the files in the repo.

Anyone deciding to ship should read the full Apple SF Arabic license agreement
first. No Apple license file was redistributed with the font files themselves.
