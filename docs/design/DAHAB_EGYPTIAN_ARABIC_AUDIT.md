# DAHAB EGYPTIAN ARABIC AUDIT & QUALITY ASSURANCE
## تدقيق جودة الصياغة المصرية عبر منصة دهب
### من الفصحى التحريرية والترجمة الحرفية إلى المصرية الراقية الذكية

---

## 1. أهداف التدقيق ومستويات الأولوية (Audit Objectives & Priority Matrix)

| الأولوية | نطاق الفحص (Scope) | المعايير الصارمة |
|---|---|---|
| **P0** (حرجة جداً) | المعاملات المالية، الدفع، الحجوزات، الطوارئ، السلامة البحرية، وتأكيدات الغرف | دقة بنسبة ١٠٠٪، وضوح لا يحتمل اللبس، خلو تام من الغموض، مع صياغة إنسانية مريحة. |
| **P1** (أساسية) | الصفحة الرئيسية، بناء الرحلات، الرفيق الميداني اليومي، محرك التغيير، دليل الأكل، والتنقل | نبرة مصرية طبيعية، رشيقة، بدون ترجمة كلمة بكلمة، اختصار نصوص الأزرار والبطاقات. |
| **P2** (تحسينات وصقل) | شارات جواز السفر، الإحصائيات، الحالات الفارغة (Empty States)، نصوص التحميل الذكية | لمسات دافئة تعزز الشعور بروح دهب وسيناء وتضفي طابعاً راقياً. |

## 3. قائمة التحقق النهائية (Verification Checklist)

- [x] **مطابقة المفاتيح (Key Parity):** الحفاظ التام على جميع مفاتيح `TRANSLATIONS` بدون حذف أو تعديل بنيوي.
- [x] **الأرقام والعملات:** اعتماد الأرقام المشرقية والأنساق الدارجة (`جنيه` / `ج.م`).
- [x] **التوقيت:** استخدام مفردات الزمن المصرية (`النهارده`، `بكرة`، `بعد بكرة`، `الساعة ٥`).
- [x] **الذكاء دون فذلكة:** الابتعاد التام عن العامية الركيكة، مع الحفاظ على روح دهب الحرة والبسيطة.
