# DAHAB EGYPTIAN ARABIC BRAND VOICE SYSTEM
## الدليل الإرشادي للهجة المصرية الراقية في منصة دهب
### "مصري شيك، طبيعي، دافي، عصري، وراقي"

---

## 1. فلسفة الصوت والهوية (Brand Voice Philosophy)

منصة دهب لا تستخدم ترجمة حرفية من الإنجليزية، ولا تعتمد على الفصحى التحريرية الجافة (Modern Standard Arabic)، ولا تنحدر إلى العامية المبتذلة أو المبالغ فيها.
الصوت المصري لمنصة دهب هو: **صديق محلي ذكي، شيك، فاهم دهب وسيناء كويس، بيثق فيه المسافر ويريحه، وبيتكلم بطريقة طبيعية ومباشرة.**

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                       أعمدة الصوت المصري لمنصة دهب                         │
├───────────────────┬──────────────────┬──────────────────┬───────────────────┤
│ 🇪🇬 مصري طبيعي     │ ✨ شيك وراقي     │ 🤝 دافي وإنساني  │ ⚡ صريح ومختصر    │
│ مش مترجم حرفياً   │ مش عامية شعبية   │ بيهتم براحة      │ كلمات معبرة       │
│ من الإنجليزي      │ أو هزار مبالغ فيه│ المسافر ووقته    │ بدون رغي وتطويل   │
└───────────────────┴──────────────────┴──────────────────┴───────────────────┘
```

### المبدأ الذهبي (The Golden Rule)
> **لا تترجم الجملة الإنجليزية كلمة بكلمة، بل أعد صياغة المعنى بالطريقة التي يتحدث بها مصري معاصر ذكي.**

### نجم الشمال (North Star)
* English: *"You made it to Dahab. We'll handle the rest."*
* الترجمة الحرفية المرفوضة: *"لقد وصلت إلى دهب. سنتولى نحن الباقي."*
* الصياغة المصرية المعتمدة: **"وصلت دهب؟ سيب الباقي علينا."**

## 2. ما نتجنبه وما نلتزم به (Avoid vs. Adopt)

| ❌ نتجنب تماماً (Banned) | ✅ نلتزم به دائماً (Adopted) |
|---|---|
| الفصحى التقريرية الجافة (*"قم بالنقر لتأكيد عملية الحجز"*) | المصرية المباشرة (*"أكّد الحجز"*) |
| الترجمة الحرفية للهياكل الإنجليزية (*"ماذا يمكنني أن أفعل الآن؟"*) | التعبير التلقائي (*"أعمل إيه دلوقتي؟"*) |
| السخرية المبتذلة أو العامية المفرطة (*"يا باشا"، "يا وحش"، "روّق على حالك ياعم"*) | الأسلوب الودود المهذب (*"يومك في دهب لسه بيبدأ"*، *"نرتبلك الساعتين دول"*) |
| المصطلحات البرمجية الغريبة (*"تم استرجاع سجلات قاعدة البيانات بنجاح"*) | لغة الخدمة الواضحة (*"لقينالك ٣ أماكن مناسبة لمزاجك"*) |
| التعريب القسري للمصطلحات الشائعة (*"تسجيل الوصول / تسجيل المغادرة"*) | الاستخدام الطبيعي للمصطلح الدارج (*"الـCheck-in"* / *"الـCheck-out"* / *"حجز الفندق"*) |

## 3. مستويات اللغة الثلاثة في المنصة (The 3 Language Levels)

تم تقسيم واجهات التطبيق إلى ثلاثة مستويات لغوية مدروسة لضمان التوازن بين الحميمية والدقة التشغيلية:

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                      مستويات الصياغة في منصة دهب                           │
├─────────────────────────────────────────────────────────────────────────────┤
│  المستوى أ (Level A): واجهات الحركة السريعة والتفاعل اليومي (Casual UI)     │
│  - الأزرار، الإجراءات السريعة، تبويب "النهارده"، المقترحات الفورية         │
│  - أمثلة: "أعمل إيه دلوقتي؟" · "ورّيني الاختيارات" · "خلّيني أظبطهالك"      │
├─────────────────────────────────────────────────────────────────────────────┤
│  المستوى ب (Level B): نصوص التجربة والمحتوى السياحي (Polished Product Copy) │
│  - العناوين، الأوصاف، تخطيط الرحلات، الأنشطة، الاستكشاف اليومي             │
│  - أمثلة: "عندك ساعتين فاضيين؟ تعالى نشوف أنسب حاجة ليهم"                  │
│           "يومك في دهب لسه بيبدأ" · "سيب لنا تنسيق التفاصيل"                │
├─────────────────────────────────────────────────────────────────────────────┤
│  المستوى ج (Level C): النصوص التشغيلية والمالية (Transactional Arabic)      │
│  - الدفع، قسائم الحجز، التنبيهات الأمنية، الطوارئ، التغيير والاسترداد      │
│  - واضحة وحاسمة بدون غموض وبدون فصحى متحجرة:                                │
│    "الدفع تم بنجاح" · "الحجز لسه بيتأكد" · "حصلت مشكلة وإحنا بنكمّل"       │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 4. صياغة الأزرار والتفاعلات السريعة (CTA & Button Patterns)

الأزرار يجب أن تكون قصيرة، محددة، ومبنية على الفعل المباشر:

| الإجراء (Context) | ❌ القديم / المرفوض | ✅ المعتمد في دهب |
|---|---|---|
| الحجز | *"ابدأ عملية الحجز"* / *"قم بالحجز الآن"* | **"احجز"** / **"احجز دلوقتي"** |
| المتابعة | *"انقر هنا للمتابعة"* | **"كمّل"** / **"كمّل رحلتك"** |
| التعديل | *"تخصيص الخطة"* | **"ظبّطها معايا"** / **"عدّل الخطة"** |
| الاختيار | *"حدد هذا النشاط"* | **"اختار ده"** / **"أضف لرحلتي"** |
| المساعدة | *"يرجى التواصل مع خدمة الدعم"* | **"محتاج مساعدة؟"** / **"كلّمنا"** |
| الاستكشاف | *"عرض جميع الخيارات المتوفرة"* | **"شوف الاختيارات"** / **"ورّيني كله"** |

## 5. الصوت عبر أطوار رحلة المسافر (Journey Stage Voice Guidelines)

### 1. طور الوصول (Early Arrival Mode)
* **الموقف:** المسافر وصل الساعة ١٠ الصبح وتسكين الفندق الساعة ٣ العصر.
* **الرسالة:** احتواء المسافر ومنع شعوره بالحيرة أو التعب.
* **النص المعتمد:**
  > "وصلت بدري؟  
  > تمام، نرتبلك الساعتين دول:  
  > سيب شنطك في مكان آمن، خد قهوتك، انزل خد لفة على البحر، وروّق لحد ميعاد الـCheck-in."

### 2. طور اليوم الميداني (Daily Companion & Spontaneous)
* **الموقف:** خلص غطسة وعنده ساعتين وقت فاضي.
* **النص المعتمد:**
  > "البحر هادي والجو رايق.  
  > عندك ساعتين فاضيين قبل الغروب؟ رشحنالك ٣ حاجات على مزاجك: قعدة قهوة على البحر، سنوركلنج خفيف في اللايتهاوس، أو لفة في الممشى."

### 3. طور الأكل وتوصيل الشاطئ (Food Now)
* **الموقف:** المسافر قاعد على الشاطئ ومحتاج أكل أو شاي بدوي.
* **النص المعتمد:**
  > "جعان؟ نفسك في إيه؟  
  > عايز حاجة سريعة وخفيفة، ولا وجبة سمك محترمة على البحر؟  
  > اطلب ونوصلهالك لحد شلتك على الشاطئ."

### 4. طور الطوارئ والتغيير (Change Engine & Recovery)
* **الموقف:** حالة البحر اتغيرت ورحلة المركب اتلغت.
* **النص المعتمد (لا نستخدم كلمة "ملغي" فقط بل نطرح الحلول فوراً):**
  > "حصل تغيير في الحجز بسبب حالة البحر.  
  > إحنا شوفنا إيه اللي اتأثر وظبطنالك ٣ بدائل جاهزة ومضمونة.  
  > اختار اللي يريحك وإحنا نكمل الباقي."

### 5. طور المغادرة (Departure Mode)
* **الموقف:** آخر يوم في دهب والاستعداد للمطار.
* **النص المعتمد:**
  > "يوم الرجوع قرب.  
  > خلينا نرتب آخر كام ساعة في دهب براحة وبدون توتر.  
  > عربيتك جاهزة الساعة ٦:٣٠، تحب تفطر وتجهز شنطتك قبلها؟"

## 6. قواعد الأرقام والتواريخ والعملة

1. **الأرقام:** نستخدم الأرقام العربية المشرقية (١، ٢، ٣، ...) في السياقات النصية الموجهة للمستخدم العربي لتعزيز الهوية البصرية المتناسقة.
2. **العملة:** نكتب **"١٬٥٠٠ جنيه"** أو **"جنيه"** أو **"ج.م"** بدلاً من "1500 EGP" إلا إذا كانت متطلبات دولية محددة.
3. **التوقيت:** نستخدم تعبيرات التوقيت الطبيعية:
   * **"النهارده"** (وليس "اليوم")
   * **"بكرة"** (وليس "غداً")
   * **"بعد بكرة"**
   * **"الساعة ٥ العصر"** · **"من ٣ لـ ٥"**

---

## 7. الضوابط الثقافية والأخلاقية (Cultural Constraints)

* **الاحترام والمهنية:** التحدث بالمصرية الراقية يعني احترام ثقافة الزائر، وتجنب أي صور نمطية، إيفيهات مستهلكة، أو مصطلحات مبالغ فيها لا تليق بمنصة سفر موثوقة.
* **البساطة والذكاء:** كل جملة يجب أن تؤدي غرضاً وظيفياً وتقدم فائدة مباشرة للمسافر.
